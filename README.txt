ESSENCE EXTRACTOR - Chrome extension
====================================

Turns a cluttered article page into a clean, readable version: just the
title and the article text, white on black, with no ads, popups or sidebars.


INSTALLING
----------
1. Move this "essence-extractor" folder somewhere permanent, for example
   your Documents folder. Chrome runs the extension from this folder, so
   don't delete or move it afterwards.

2. Open Chrome and type this into the address bar:
       chrome://extensions

3. Turn on "Developer mode" using the switch in the top-right corner.

4. Click "Load unpacked" (top-left) and choose the "essence-extractor"
   folder (the one containing manifest.json).

5. Click the puzzle-piece icon in Chrome's toolbar and click the pin next
   to "Essence Extractor" so the "E" button stays visible.

6. Refresh any tabs that were already open before you installed it.


USING IT
--------
Open an article and click the "E" button in the toolbar.

While a page loads, the extension quietly keeps track of the article text.
If the site later hides or cuts off part of the article, the extension
still uses the fullest version it saw. Pages are only changed when you
click "E". Refresh the page to get the original back.


THEMES AND FONTS
----------------
To change the look, right-click the "E" button and choose "Options".

- Theme: Black, Dim, Sepia, Gray or Light.
- Font: Sans-serif, Serif (Georgia), Times, Verdana or Monospace. The
  website's own font is never used.
- Text size: Small, Medium, Large, Extra large or Huge.

Changes apply right away, including to articles you already have open.


NOTES
-----
- When Chrome starts, it may show a warning about "developer mode
  extensions". That's normal for extensions not installed from the
  Chrome Web Store. Dismiss it, but don't click "Disable".

- The extension needs permission to read all websites so it can follow
  article text as pages load. Nothing is sent anywhere; it all stays in
  your browser.

- It works best on news and blog articles. On pages without a clear block
  of article text, clicking "E" does nothing.

- It doesn't work on Chrome's own pages (chrome://...) or the Chrome Web
  Store.
